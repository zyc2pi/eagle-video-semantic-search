# 视频语义搜索（Eagle 插件）

用自然语言（中文/英文）在 Eagle 素材库中搜索视频画面，结果精确到**场景时间段**，并可一键在 Eagle 主窗口定位素材。

推理与索引由本地 [Auto-scenes-extraction](file:///D:/Auto-scenes-extraction-1.3.0) 服务提供（FG-CLIP2 / CLIP + Lance 向量索引），插件通过 `http://127.0.0.1:5006/api/v1/*` 调用，无任何云端依赖。

## 依赖

- Eagle 4.0+（Windows）
- 本地 Auto-scenes-extraction 1.3.0 项目（默认路径 `D:\Auto-scenes-extraction-1.3.0\Auto-scenes-extraction-1.3.0`，可在插件设置中修改），其中需已下载嵌入模型（默认 `qihoo360-fg-clip2-base`）

## 安装（开发者模式）

1. Eagle 中按 `P` 打开插件面板 → 开发者选项 → 导入本地项目 → 选择本文件夹
2. 或者：右键插件 → Pack Plugin 打包为 `.eagleplugin` 双击安装

## 使用

1. 打开插件，等待右上角服务状态变绿（插件会自动拉起 Python 服务，首次约 10~30 秒）
2. 点击「索引整个库」（或先在 Eagle 选中文件夹/素材再点对应按钮，文件夹**递归包含所有子文件夹**）。索引是**增量**的，新增素材后重复点击即可；进度条旁的「停止」可随时中断（已完成部分保留，下次续跑）
3. 搜索方式（三种）：
   - **文本**：输入描述（如「夜晚的城市街道」）回车
   - **以图搜视频**：直接在插件窗口 `Ctrl+V` 粘贴一张图片
   - **以片搜片**：在 Eagle 选中视频素材后点「以选中素材搜相似」；或把鼠标悬停在任一结果卡片上点「找相似」
4. 搜索框旁的「**范围**」按钮设置搜索范围（三种搜索方式都遵循，全部递归子文件夹）：整个库 / 跟随 Eagle 当前选中的文件夹 / 在插件内的 Eagle 文件夹树中**勾选多个文件夹**（按库记忆，换库自动重置）
5. **鼠标悬停**结果卡片自动小窗循环播放该片段（mp4/mov/webm；其余格式点击预览）；点击卡片在顶部大窗预览；「在 Eagle 中定位」跳回主窗口选中素材
6. 悬停卡片左上角可**勾选**，然后：
   - 「导出片段」：切成 MP4 并自动导入回 Eagle（放入 `语义搜索_<查询词>` 文件夹、打上查询词标签、注释里记录来源和时间码）
   - 「打标签」：直接给源素材打上查询词标签，之后 Eagle 原生搜索也能搜到
   - 未勾选时默认应用到全部结果（导出超过 50 条会要求先勾选）
7. 设置页可开启：**AI 查询增强**（deepseek-v4-flash 中英双语改写，key 在设置页填写）、**跨视频去重**、**二阶段精搜**（MiniCPM 复核，更准但慢）；还有「重启搜索服务」按钮
8. 搜索框支持**历史记录**下拉（最近 20 条）
9. 点开任意场景预览后点「**生成提示词搜索**」：本地 MiniCPM 视觉模型分析画面生成 2~4 个检索短语，随后自动做**文本×视觉混合检索**（两路命中融合排序，带「双」标的最可信）；同一片段的提示词有缓存，设置页可开「MiniCPM 常驻显存」提速到 ~2 秒
10. 设置页可调**全部检索/索引参数**：视觉检索的聚合方式（mean 严格 / max 宽松）与采样帧数；建索引的采样间隔、分辨率、最小场景长度、批大小、场景切分阈值等（改动只影响之后索引的新视频）
11. **负向提示词**：搜索 `跑步 -操场` 表示要跑步画面但排除操场
12. 结果页顶部**视图栏**：按相似度/时长/视频名排序、按最短时长过滤、**按视频分组折叠**；预览打开后 `←/→` 切换结果、`Esc` 收起
13. **索引自动对比**：打开插件自动提示"N 个新视频未索引"；建索引任务可**排队**（连点几个文件夹依次执行）；设置页有「重建当前库索引」（清理已删素材的失效条目）和「查看服务日志」
14. 缩略图缓存持久化（重启服务后结果页秒开，超 2GB 自动清理）；显存不足时报错会给出可操作的提示
15. **向量中心化**（设置页，试验性）：减去库平均画风再比相似度，整库画风相近时大幅减少以图/以片搜的误命中（小索引上无意义，建议几十个视频以上再开）
16. 预览面板：**时间轴**显示该视频全部命中场景（点击跳转）；「准备拖拽片段」把片段切成 H.264 文件后可**直接拖进 PR/剪映**（或在文件夹中显示）
17. **结果存档**：视图栏「存结果」把当前搜索结果存成存档，「存档…」随时载入/删除（存于插件目录 saves/）
18. **静默自动索引**（设置页开关）：插件以 serviceMode 随 Eagle 启动在后台运行，开启后每 10 分钟检查库内新素材并自动增量索引；关闭时后台完全安静（不启动 Python 服务），打开插件窗口才连接

## 说明

- 相似度分数为 `余弦 × logit_scale`（约 ×100）：文本搜索 FG-CLIP2 建议阈值 ≈ 11，CLIP ≈ 21
- 以图/以片搜的图像相似度天然偏高，独立阈值默认 40（设置中可调），结果按相似度排序、最多 100 条
- 索引存储在原项目 `indexes/<模型名>/eagle_<库名>_<模型名>.lance`
- 中文搜索需 FG-CLIP2 模型；CLIP 模型仅英文有效
- 从库中删除素材后，旧索引仍会返回该视频（结果中标灰提示）；可在原项目中删除对应 `.lance` 后重建
