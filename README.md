# 视频语义搜索（Eagle 插件）

用自然语言（中文/英文）在 Eagle 素材库中搜索视频画面，结果精确到**场景时间段**，并可一键在 Eagle 主窗口定位素材。

推理与索引由本地 Auto-scenes-extraction 服务提供（FG-CLIP2 / CLIP + Lance 向量索引），插件通过 `http://127.0.0.1:5006/api/v1/*` 调用。基础检索本地运行；可选 AI 查询增强会调用外部服务，关闭该选项即可不用云端增强。

当前插件版本 **1.1.0**，配套后端使用 Eagle 协议 **2**；最近的修复与验证见 [UPDATE-20261007.md](UPDATE-20261007.md)。源码按 [MIT 许可证](LICENSE) 开源。

## 依赖

- Eagle 4.0+（Windows）
- 本地 [Auto-scenes-extraction](https://github.com/zyc2pi/Auto-scenes-extraction) 1.3.0 项目，需支持 Eagle 协议 **2**（默认路径 `D:\Auto-scenes-extraction-1.3.0\Auto-scenes-extraction-1.3.0`，可在插件设置中修改），其中需已下载嵌入模型（默认 `qihoo360-fg-clip2-base`）

本仓库只包含 Eagle 插件源码、测试和开发记录；后端 Python 环境、模型权重和索引需单独准备，安装方式见后端仓库说明。

## 安装（开发者模式）

1. 克隆本仓库，或在 GitHub 点击 Code → Download ZIP 并解压：

   ```powershell
   git clone https://github.com/zyc2pi/eagle-video-semantic-search.git
   ```

2. Eagle 中按 `P` 打开插件面板 → 开发者选项 → 导入本地项目 → 选择包含 `manifest.json` 的本文件夹。
3. 在插件设置中填写本机后端项目路径，保存后连接服务；无需安装前端依赖或构建。
4. 如需分发 `.eagleplugin`，请在干净的源码副本中使用 Pack Plugin；使用过的目录可能包含密钥配置、素材路径和仓库数据，不应直接打包分发。

## 使用

1. 打开插件，等待索引按钮左侧状态灯变绿（插件会自动拉起 Python 服务，首次约 10~30 秒）
2. 点击「索引整个库」（或先在 Eagle 选中文件夹/素材再点对应按钮，文件夹**递归包含所有子文件夹**）。索引是**增量**的，新增素材后重复点击即可；整库索引还会自动清理已从 Eagle 删除的失效路径，不会重新分析已有素材；进度条旁的「停止」可随时中断（已完成部分保留，下次续跑） 进入插件时短暂显示「加载搜索服务…」，连接成功后仅在索引按钮左边显示绿灯；悬停绿灯可查看连接状态。设置位于工具栏右侧，「新搜索」紧接「搜索仓库」。
3. 搜索方式：
   - **文本**：输入描述（如「夜晚的城市街道」）回车
   - **以图搜视频**：直接在插件窗口 `Ctrl+V` 粘贴一张图片
   - **当前帧找相似**：结果卡片点「选帧找相似」，在预览中暂停、拖动进度或逐帧调整，点击「以当前帧找相似」。只使用点击时固定的一张画面，候选镜头按最相似的代表帧打分。
4. 工具栏「**筛选**」汇总阈值、文件夹范围、素材加入时间及结果内筛选，新搜索尚无结果时也可打开。新搜索中的范围支持整个库 / 跟随 Eagle 当前选中的文件夹 / **指定文件夹** / **排除文件夹**；指定与排除支持多选且递归子文件夹（换库自动重置），与时间条件一起作用于检索。仓库主题中同一菜单提供已存结果的阈值、文件夹包含／排除和时间筛选，改动即时生效，不请求搜索、不改写主题；若要永久修改后续更新时的搜索条件，仍使用「主题管理 → 编辑条件」。
5. **鼠标悬停**结果卡片直接播放原视频中对应的时间段（mp4/mov/webm；其余格式双击尝试原生预览）；双击卡片在右侧详情栏预览；「在 Eagle 中定位」跳回主窗口选中素材。悬停立即加载，元数据定位后立即请求播放；双击复用悬停播放器并从片段开头播放，快速双击也复用在途加载，同视频切换时间段不重载。展开封面复用已有缩略图，不额外抽帧。拖出始终是完整原视频，已选素材按视频去重后检查文件；没有整段/片段选择、片段准备或视频切片转码。连续1.5秒没有实际播放推进时重载原文件一次，仍停滞1.5秒直接提示错误；正常播放会延后恢复期限，定位跳转不计作播放进度。不支持的编码可在Eagle中打开或拖出原视频使用。原生播放仍需读取、定位和解码，宿主持续停帧的具体原因仍在核验。
   - 展开已就绪的悬停视频不再请求封面；封面加载失败不会打断原视频播放。
   - **拖到 PR / AE**：按住结果缩略图拖出完整原视频；拖已勾选的卡片时批量拖出所选素材，同视频自动去重。拖未勾选卡片只带出当前视频。原视频拖拽不依赖搜索服务。
6. 普通搜索和主题结果统一支持**左键单选**、**Ctrl+左键追加／取消单项**、**Shift+左键连续多选**；Shift 按当前筛选、排序和分组后的显示顺序追加整段，保留其他已选片段。左上角复选框仍可直接勾选。**右键打开完整的「整理所选」菜单**：在已选片段或结果空白处右键保留多选，在未选片段右键先单选该片段。菜单包含添加到主题、从主题移除、调整评分、取消全部选择、添加标签和添加到新文件夹，依当前页面及选择状态显示或禁用，与顶部入口共用操作。标签／文件夹名称默认使用当前搜索名称（仓库主题中使用主题名称），可在弹窗中修改；新文件夹创建在当前 Eagle 库根目录。标签和文件夹操作作用于完整原素材，同一素材的多个片段自动合并，保留已有标签和文件夹归属；完成后显示成功、失败和失效数量。
7. 设置页可开启：**AI 查询增强**（deepseek-v4-flash 中英双语改写，key 在设置页填写）、**跨视频去重**、**二阶段精搜**（MiniCPM 复核，更准但慢）；还有「重启搜索服务」按钮
8. 搜索框支持**历史记录**下拉（最近 20 条）
9. 「显示 → 预览方式」可选择**右侧素材详情**或**顶部预览（双击展开）**，记住上次选择。顶部模式还原双击卡片后在列表上方展开预览的用法，预览与素材列表之间的横线可上下拖动调高，并保留偏好，缩窗自动限高给列表留出空间；收起后列表恢复高度；两种方式共用播放器，切换保留当前片段、播放状态、进度及勾选，不重新搜索。右侧模式接缝可左右拖动调宽并保留偏好，缩窗自动限宽、放大恢复，接缝聚焦后也可用 ←/→ 调宽。普通搜索和仓库主题都可逐帧选图，仓库主题还可设置封面。
10. 设置页可调**全部检索/索引参数**：剪贴板和历史视觉查询的聚合方式（mean 严格 / max 宽松）与历史片段采样帧数；当前帧查询固定使用一张图和 max 聚合。建索引参数仅影响之后索引的新视频。默认**按内容自适应选帧**，复用切镜头时已计算的 FG-CLIP2/CLIP 特征，先选整体代表画面，再补充差异画面；差异充分覆盖后提前停止，默认每镜头最多 12 帧，可调 1～32，无额外解码、模型推理或下载。不固定取首/中/尾，画面相同可能只留一帧；原视频保持完整，既有索引不自动改变。上限越大，索引和后续搜索比较量可能增加；未采到的短暂动作无法补回。仍可切回原首/中/尾三帧，或选择 **DINOv3 + CSES** 模式（按时长分配预算，最多编码128帧、保留32帧，有额外推理开销）；DINOv3需后端 `onnxruntime==1.24.4` 和 `python/python.exe tools/prepare_dinov3.py` 准备约115MB权重，并重启服务。
11. **负向提示词**：搜索 `跑步 -操场` 表示要跑步画面但排除操场
12. 结果页顶部「显示」菜单提供相似度/时长/视频名排序及按视频分组；「筛选」集中视频名、标签、片段时长上下限及人工评分状态；「整理所选」集中收录、改分、移除、标签和新文件夹操作。预览打开后 `←/→` 切换结果，`Esc` 优先关闭菜单，再收起预览。
13. **索引自动对比**：打开插件自动提示"N 个新视频未索引"；后端将两插件任务串行排队，搜索插件监视自己的任务 ID，断线后重连，避免重复提交。设置页「索引任务记录」可看进度、逐素材结果、停止指定任务或仅重试失败项。
14. **预览图缓存**：主题和搜索共用会话缓存，默认最多 5,000 张、缓存数据预算 128 MB，最近浏览的图片优先保留；命中直接显示，重复请求合并，不重新压缩图片。可在「设置 → 预览图缓存」调整两个上限，保存后立即生效，任一项设为 0 关闭；预算不含页面及解码占用。重载插件会清空会话缓存，后端已生成的 JPEG 磁盘缓存继续保留（服务启动时若超过 2 GiB，整体清理）。显存不足时报错会给出可操作的提示。
15. **向量中心化**（设置页，试验性）：减去库平均画风再比相似度，整库画风相近时大幅减少以图/以片搜的误命中（小索引上无意义，建议几十个视频以上再开）
16. 预览面板：**时间轴**显示该视频全部命中场景（点击跳转）；素材标签 chips 点击即以该标签为词再搜索
17. **搜索仓库**：视图栏「保存到仓库」保存当前筛选后的全部结果（包含未滚动加载的片段）及搜索条件。工具栏「搜索仓库」打开独立卡片页，支持主题名称搜索、单层分类、重命名和移动分类；卡片显示素材数、片段数及最近更新成功时间。打开主题后可使用独立时间筛选，选择近半年、近 1～5 年或自定义起止日期，立即按素材加入 Eagle 的时间筛选已保存结果；无需搜索服务，不写入存档、不改变搜索条件及更新时间。切回「不限时间」恢复已保存的全部结果，筛选范围在本次插件会话内保留。缺少导入时间的素材不参与时间筛选。「更新结果」是独立操作，按原先保存的搜索条件重新搜索，预览并确认变化后替换旧结果，在片段上标记新增；主题栏只显示素材数、片段数和更新时间，不提供只看新增筛选。仅改名称、分类不触发搜索；搜索或写盘失败保留原快照。
18. **静默自动索引**（设置页开关）：插件以 serviceMode 随 Eagle 启动在后台运行，开启后每 10 分钟检查库内新增和已删除素材并自动同步索引；关闭时后台完全安静（不启动 Python 服务），打开插件窗口才连接
19. **库统计**（设置页）：视频总数/索引覆盖率/提纯产出、标签 Top20 分布、时长分布
20. 预览面板显示素材已有的**标签**，点击任意标签直接搜索。
21. **安全索引迁移**：使用后端 `tools/index_package.py` 在停机窗口导出、导入、迁移或回滚。旧版在线直接覆盖已移除。详见 [更新与迁移说明](UPDATE-20260929.md)。
22. **模型升级通道**：设置页模型下拉动态读取 `models/` 目录——放入新的嵌入模型文件夹即可选用（自动过滤重排/多模态模型）
23. **素材时间筛选**：工具栏中「搜索仓库」后面的时间选择器支持不限时间、近半年、近 1～5 年及自定义起止日期。使用 Eagle 的 `importedAt` 导入时间，与文件夹范围取交集后再检索；相对日期在每次搜索／仓库更新时重新计算，自定义日期包含结束当天。缺少日期的素材在启用时间条件时会被排除并提示；全部不可读时拒绝搜索，避免误清空主题。新增素材须先完成索引才能被搜索到。
24. **自选主题封面**：卡片点「选封面」进入主题，选择一个素材，在预览中暂停并拖动进度，也可用「上一帧／下一帧」精确调整，点击「当前帧设为封面」。封面图片随主题保存，后续更新搜索结果仍保留；不改变最近搜索更新时间。主题页可「恢复默认封面」。默认封面取命中片段的画面，抽帧失败时回退 Eagle 缩略图。
25. **仓库框选与批量管理**：在卡片或列表的空白处拖拽框选，拖到上下边缘可滚动继续选择；Ctrl / Shift 框选追加选择，Esc 取消本次框选，单击空白清空选择。保留 Ctrl 点击切换选中、Shift 按显示顺序选择范围；筛选后清除隐藏选择。右键所选主题或空白处可批量修改分类、删除所选主题；删除确认后移入仓库回收站，不删除 Eagle 原素材。失败项保留选中供重试，版本冲突需重新打开仓库核对。
    修改分类及保存/编辑主题时，可直接输入新名称并确认创建，也可搜索、点击已有分类，支持 ↑ / ↓ 与 Enter。分类按最近成功使用顺序优先列出，按素材库记住；取消不会创建分类，同名自动复用。最近使用记录从新版首次使用开始累计。
26. **仓库视图与容量**：卡片/条栏视图在重载后保留，偏好不可用时保留本次会话选择。每批显示 60 个主题，点击「显示更多」继续；勾选不重建卡片或重复读取封面。
27. **人工整理主题片段**：打开主题，选好片段后点击「整理所选 → 从主题移除」，批量移除当前所选片段。立即生效，可用「撤销」恢复本次操作；「已移除」列表支持按视频名搜索、勾选及恢复，清空主题后仍可打开。恢复立即回到已保存结果，同时解除排除，并遵守当前时间、时长、排序和分组条件。移除记录随主题持久保存，之后「更新结果」仍排除相同素材和原始起止帧的片段；同视频其他片段、其他主题及 Eagle 原素材不受影响。人工整理无需搜索服务，不改变最近搜索更新时间；写盘失败或版本冲突保留原结果及勾选。
28. **人工添加与打分**：在搜索结果或其他主题中勾选片段，点击「添加到主题」，选择当前库的一个已有主题。评分面板展示目标主题高、中、低分片段及时间，点击参考可复制分数；来源分数不会自动沿用。可逐个填写，也可统一打分后逐个调整：↑/↓ 调整 0.1，Ctrl+↑/↓ 调整 1，←/→ 切换待添加片段并保留分数；统一分数框调整后须点击「填写未评分」，关闭「只填未评分」后可「覆盖全部分数」。切换目标会清空评分。置顶分取当前参考的最高分，之后保持固定，按相似度排序时优先于其他同分片段；空主题请手动填写，允许 0 分。完成后留在来源页面并清空勾选；取消或失败保留来源及选择。已有片段更新人工分数、已移除片段重新加入并解除排除；未来更新结果仍保留人工片段及分数，不写 Eagle 原素材。目标版本冲突时先「刷新参考」核对，再重试；刷新参考保留已填分数，已选置顶值保持固定。

29. **主题内查找**：「筛选」菜单内可按视频名查找，并选择「人工评分」或「未人工评分」。与时间、时长条件取交集，即时过滤已保存结果；隐藏片段的勾选自动清除。清空名称并选择「全部片段」可恢复显示。查找不请求服务、不写盘，条件按库和主题在本次插件会话内保留；新搜索使用自己的结果。
30. **就地调整评分**：在当前主题内勾选片段，点击「调整评分」。面板固定当前主题，已有人工分数及固定置顶值以完整精度带入；尚未人工评分的片段留空，由用户填写。支持原有逐片段、统一分数和键盘操作。保存后留在当前主题，保留查找条件并清空勾选；取消或失败保留结果和选择。版本冲突需显式「刷新参考」；已从主题移除的片段不能通过改分重新加入。
31. **继续上次浏览**：进入主题再返回仓库时，恢复名称搜索、分类、视图、已加载批次及滚动位置；重新打开主题会恢复会话内的排序、分组折叠和已加载片段，先从顶部显示。若该主题上次停留在非顶部，右下角弹出约 4 秒的「回到上次浏览位置」按钮，点击才恢复原滚动位置，忽略后自动淡出。恢复成功后另显示约 2 秒提示，可点「回到顶部」从头浏览。位置按素材库和主题保留于本次插件会话，重载后不保留；改变查找条件或排序会清除当前旧位置入口，资源变化时位置会校验并尽量保留附近内容。

32. **评分总览与补齐分数**：收录和就地改分面板提供可点击总览，每批最多 60 个片段；显示完整分数、固定置顶和未评分状态。「下一个未评分」循环跳转。默认「只填未评分」，统一分数和批量置顶保留已有有效分数（包含 0）；取消该选项后才覆盖全部。就地改分中未人工评分的机器分数不当作已填值。
33. **收录与改分撤销**：打开具体主题后，「另存为主题」旁的「撤销整理」按钮或 Ctrl+Z 撤销最近一次成功的收录/评分，可连续撤销；恢复新增、重复评分、重新加入前的排除状态与原分数。按库在当前会话保留最多 20 步，全部历史估计载荷限 64 MiB；重载插件清空撤销历史。输入框内 Ctrl+Z 保留文字编辑行为，面板打开或搜索/写入繁忙时不触发主题撤销。目标后来被更新、改名、分类或星标时，版本冲突会阻止旧撤销；写盘失败保留记录可重试。该快捷键不撤销 Eagle 标签/文件夹写入，也不替代主题移除入口原有的「撤销」。
34. **星标常用主题**：仓库卡片、条栏和打开后的主题可点 ☆/★ 切换常用标记，持久保存且不改变最近搜索更新时间。仓库默认常用优先，再按搜索更新时间排序；「★ 常用」只显示星标主题，与名称/分类筛选取交集。收录目标下拉也优先显示星标主题，并显示分类以辨认同名主题。

35. **连续收录与重复保护**：成功添加后，按素材库记住最近目标，下次打开自动读取该主题。面板显示新增、已收录、重新加入数量，以及当前片段在目标中的原分数。重复片段默认「保留目标原分」，无需再次评分，也不改变机器/人工评分及置顶模式；选择「重新评分」才执行第 28 项中的重复改分。新增和重新加入片段仍须填写分数，重新加入解除排除。全部重复且保留原分时不写盘；取消和失败不改变最近成功目标。
36. **右侧详情栏**：点击片段，在右侧统一查看视频预览、所属主题、全部素材标签、Eagle 星级、片段人工评分或相似度，以及尺寸、时长、格式、大小、帧率、日期和原文件路径。主题可点击打开，标签可点击搜索；缺失信息显示「未获取」。原有浅色/深色配色随 Eagle 保留，不额外写入素材信息。
37. **更新变化预览**：「更新结果」或修改搜索条件后，先查看新增、消失和本次未命中的人工保留片段，点击「应用更新」才替换结果。列表展开后分批显示；零结果也须确认。取消保持旧结果、选择和条件编辑内容；写盘失败可直接重试，不重复搜索。其他窗口已修改主题或切换素材库时，旧预览不能覆盖当前版本。
38. **单主题历史恢复**：「主题管理 → 主题历史」读取当前保留的仓库备份，同一主题版本只列一次。先预览，再点击「恢复此主题」，恢复该版本的结果、人工评分、审阅进度、移除记录、封面和主题设置，其他主题保持当前状态；已删除的历史分类归入未分类。恢复无需搜索服务，恢复前自动备份，恢复后仍可继续编辑。历史范围受整库备份保留策略限制，默认最近 10 次仓库写入，并非每个主题 10 份或永久历史。
39. **复制主题**：打开主题或仓库卡片的「编辑」，点击「复制主题」，修改副本名称后「创建并打开副本」。复制已保存的完整主题，包括搜索条件、全部片段、人工评分、审阅进度、持续排除记录、封面、分类和常用状态；不会只复制当前筛选结果，也不带入编辑器中尚未保存的修改。副本具有独立身份，之后的更新、改分、移除和删除互不影响；无需搜索服务。复制不改变原主题和最近搜索时间，写入失败可重试；原主题已被其他窗口修改时，须重新打开后再复制。

40. **结果内组合筛选**：统一「筛选」菜单中，普通搜索和仓库主题都可按视频名、素材标签、片段时长上下限及人工评分状态缩小已有结果。所有条件取交集，时长以秒计并包含边界；标签填写完整名称，多个标签用中英文逗号分隔且全部满足。主题的本地阈值与文件夹范围也参与交集，包括人工收录片段；不请求模型、不删除原结果，隐藏片段自动取消勾选。「清除结果筛选」清除组合条件及最短时长，主题中同时恢复不限阈值、文件夹和时间；新搜索的搜索前条件保持。切换主题及返回原搜索会恢复各自的会话条件。
41. **片段主题归属**：右侧详情栏显示当前片段的完整主题归属，点击主题可打开。归属使用当前库的已存结果，按素材及原始片段边界匹配，已移除片段不计入；不重新推理或修改主题。仓库和主题管理均不再提供跨主题比较入口。

### 仓库数据与兼容

- 仓库保存在插件目录 `warehouse/`，按 Eagle 素材库分别保存；采用临时文件写入后替换，备份时保留整个目录。
- 原 `saves/` 存档自动导入所属库，保留原文件。旧存档缺少完整条件，首次更新前需要确认新的文本搜索条件；不会推测历史阈值或图片来源。
- “跟随 Eagle 选中”的范围保存为当次选中的文件夹，以后更新包含这些文件夹内新加入的素材及其子文件夹。原文件夹失效时提示重新选择。
- 查询图片随主题保存，视频查询记录来源素材与片段；来源失效时保留结果并提示重新选择。新增标记按素材与原始片段边界比较，保存至下一次更新；首次保存没有比较基准，因此不标记新增。
- 当前帧搜索保存固定截图及源帧信息，结果上方可查看查询画面。转文字主题保存最终编辑的查询词和截图；更新时直接重放查询，不重新生成描述。截图主题在源视频失效后仍可更新，历史整片段主题仍需来源视频可用。
- 仓库采用轻量清单与内容寻址资源文件，结果、查询来源、封面按需读取；备份请保留整个 `warehouse/`，不能只复制清单 JSON。旧格式在后续成功保存时升级，修改前保留备份。
- 「备份 / 回收站」支持主题恢复、历史版本恢复和带校验和的仓库包导出/合并导入。默认最近 10 个有效备份、回收站 30 天，可调整；未知或损坏的备份不会自动清理。孤立资源保守保留。
- 回收站与活动主题都保存资源引用，删除主题不会把查询图片和片段结果重新塞入清单；到期清理前校验资源，坏记录保留。仓库包保留回收站内容，导入导出在后台线程执行；处理中可见状态，错误保留原件，异常中断需核对实际写入结果。
- 修改名称、分类、排序、分组和最短时长均不重新搜索，不改变搜索更新时间；只有查询条件变化才需要服务。
- 浏览仓库主题后点击「新搜索」，恢复进入主题前的关键词、完整搜索结果、排序、时长筛选和勾选；连续切换主题也保留原搜索，不重新发起请求。没有此前搜索时返回空搜索页。

### 可靠性更新

- 设置校验通过且原子写入成功后才更新内存；合法视觉阈值 `0` 保留。损坏配置不会自动覆盖，可在设置中明确选择备份原件并保存新设置。
- 查询参数在下次查询生效；索引参数作用于之后新处理的视频，重建可应用到整库；密钥变化须重启服务。端口/路径变化会尝试重新连接，不擅自终止旧服务。
- 「取消等待」保留上次成功结果并忽略迟到响应；它不保证后端 GPU 已停止计算。原视频预览失败显示错误并可重试，不生成替代视频。
- 批量整理显示逐素材失败原因，支持仅重试失败项；加入文件夹重试复用原文件夹，不创建同名副本。
- 素材映射使用按库短缓存，设置中可主动刷新；整库索引强制读取最新清单。单视频大量命中每批显示 60 条，组内最高分不受排序影响。
- 两插件需要配套协议版本 2 后端；旧库名索引保留但不自动混入新版查询。首次升级请离线迁移可确认归属的旧索引，或在新身份下重新建索引。

### 验证

除 `AGENTS.md` 中的语法与单元测试外，可运行 `node tests/warehouse.smoke.js` 做独立浏览器交互测试。需要可解析的 `playwright` 包、本机 Microsoft Edge 和 PATH 中的 `ffmpeg`（或通过 `FFMPEG` 指定路径）；测试使用模拟素材、模拟服务与内存存储，并临时生成短视频验证真实选帧截图，不读取用户库或配置，不操作正在使用的 Eagle 窗口。包含九张卡片的多排布局、主题内时间筛选、固定封面、设置失败及批量重试回归。

存储合成基准：`node tests/warehouse.benchmark.js`，包含批量分类与逐项保存的对比。本轮依用户要求不执行真实搜索测评；已有离线指标工具见 [EVALUATION.md](EVALUATION.md)，未执行、未人工标注的样例不计算准确率，不以合成测试代替真实库验收。
